# Sallora back end

Hono 4 on Node.js + TypeScript, created from the official `create-hono` `nodejs` template, with SQLite through Drizzle ORM.

Run it from the repository root (see the root [README](../README.md)):

```bash
npm run db:migrate   # creates data/sallora.db and its tables
npm run dev          # http://localhost:3000/health
npm test
```

- Data model: [`src/db/schema.ts`](src/db/schema.ts), explained with a diagram in [`docs/data-model.md`](../docs/data-model.md)
- Migrations: [`drizzle/`](drizzle/), generated by `npm run db:generate -- --name what-changed`
- Settings: copy [`.env.example`](.env.example) to `.env` (git-ignored)
