# Sallora front end

React 19 + Vite 8 + TypeScript, created from the official `create-vite` `react-ts` template.
So far it has one page: the landing page (`src/App.tsx`).

Run it from the repository root with `npm run dev` (see the root [README](../README.md)). It serves http://localhost:5173 and forwards `/api/…` calls to the back end.

- Brand tokens: `src/styles/tokens.css` (copied from [`docs/brand-book.md`](../docs/brand-book.md))
- Every string in Albanian, Macedonian and English: `src/i18n/messages.ts`
